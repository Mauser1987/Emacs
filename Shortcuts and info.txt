Emacs shananigans

The "Panic Button"
    C-g : Cancel (Get me out of here! Stops any command).

Files & Saving
    C-x C-f : Find File (Open a file or create a new one).
    C-x C-s : Save the current file.
    C-x C-w : Write to a new name (Save As...).

The File Manager (Dired)
    C-x d : Open the Directory (File list view).
    d : Mark a file for deletion.
    x : Execute the deletion (delete marked files).
    R : Rename a file (shift+r).

Windows (Splitting the Screen)
    C-x 3 : Split window Right (side-by-side).
    C-x 2 : Split window Below (top-and-bottom).
    C-x o : Jump to the Other window.
    C-x 1 : Keep only 1 window (Maximize current).
    C-x 0 : Close (0) the current window.

The "Do Anything" Command

    Alt + x (M-x): Run a command by name (like load-theme, eshell, etc.).
